# Tutorial / 游戏设计探索方向

一个目录对应一个探索方向。每个方向保留自己的问题、Demo、调研依据、实验方法和结果，方便独立体验，也方便继续迭代。

| 目录 | 探索内容 | 运行与验证 |
| --- | --- | --- |
| [impact-combat](impact-combat/README.md) | 动作游戏打击感：命中停顿、扫掠碰撞、输入缓存、受击、镜头与声音 | 原生 H5；Node 行为回归 |

## 新方向的组织约定

- 目录使用简短的英文小写名称，以连字符分隔，例如 `movement-feel`。这里只列命名示例，不创建空方向。
- `README.md` 说明探索问题、如何运行、可调整的变量及如何判断结果。
- 实现与运行所需资源放在方向内部，避免让一个方向依赖另一个方向的文件。
- 需要时用 `docs/` 保存设计、调研和验证记录，用 `tests/` 保存有意义的行为回归。简单实验不必强行补齐目录。
- 把可复用的方法提炼到仓库级 `.agents/skills/`，并链接回对应原型；不要复制整套研究资料到 Skill 中。
- 新增方向后，同步更新本页和[仓库首页](../README.md)索引。

从仓库根目录启动静态服务后，使用 `/tutorial/<方向名>/` 访问对应 H5 原型。方向内的 README 也可以提供独立启动方式。
