# 验证记录

验证日期：2026-10-30。使用 Playwright 驱动 Chromium 浏览器和 Node 内置测试运行器，检查桌面视口、手机触控视口、固定帧步和输入状态。以下是已有原型的验证结果，不代表跨浏览器或实际手机硬件的完整兼容性认证。

## 战斗与实验面板

- 默认站位的第一段轻击能够命中。
- 完整与原始预设的标准重击伤害均为 42，目标剩余生命一致。
- 默认完整预设的重击停顿显示 110 ms，原始预设显示 0 ms。
- 连续三段轻击都能命中，并进入第三式。
- 连续三次重击能够打破装甲目标的三层装甲。
- 单独更改反馈开关后，面板显示「自定义反馈」。
- 原始预设关闭全部五个反馈开关。
- 强度滑条调至 150% 时，显示值同步更新。

## 试炼

- 持续移动避开攻击后，30 秒倒计时正常结束，显示完成结算。
- 不闪避并承受五次攻击后，生命归零，显示失败结算。
- 重试可以关闭结算层并恢复五格生命。
- 返回自由练习可以关闭结算层并恢复练习模式。

倒计时场景使用浏览器虚拟时钟推进，以覆盖完整的 30 秒流程。

## 布局与输入

- 桌面 1440 像素宽度下完成视觉检查。
- 手机 390×844 视口没有横向溢出。
- 在启用触控能力的浏览器上下文中，轻击触控按钮只触发一次攻击。
- 用浏览器的真实触控事件长按移动按钮，释放后按钮及移动输入恢复。
- 移动后反向重击产生正确的挥空结果。
- 窄屏镜头采用裁切与跟随，角色不会横向压缩。
- 修正后的触控流程未捕获 JavaScript 页面异常。

## 静态检查

- `node --check game.js` 通过。
- HTML 中没有重复 ID。
- HTML 引用的本地脚本与样式均存在。

## v1.1 优化回归

`node --test tests/combat.test.cjs`：8 项通过。

- 刃线扫掠会随左右方向镜像，并拒绝明显超出剑刃可视范围的目标。
- 阻尼镜头弹簧在整段步长与 240 Hz 分步积分下保持相同结果。
- 20、30、60、144 fps 下重击都产生一次 42 伤害，命中目标位置一致。
- 原始／完整预设保持相同生命变化和接触几何；原始预设的停顿为 0。
- 重击中的提前轻击会进入收招队列；空格闪避优先于随后到来的轻击。
- 三段连击在提前输入下仍按一、二、三式命中。
- 装甲目标三次重击破防，命中火花保持在接触位置。
- 20 fps 下试炼倒计时按 30 秒现实时间结束；单次 31 秒渲染卡顿不会让试炼永久延长。

浏览器回归还检查了默认轻击、默认 90 ms 重击停顿、实测停顿读数、移动端布局和控制台错误。`output/playwright/v11-desktop.png` 是优化版本的桌面截图。
